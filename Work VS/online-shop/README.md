# Интернет-магазин на Java и Spring Boot

Сервер написан на Java 17 и Spring Boot 3.5. Интерфейс использует HTML, CSS и JavaScript. Данные товаров, пользователей, заказов и корзин хранятся в файловой базе H2 (`data/shop.mv.db`). Права покупателя и администратора проверяются сервером через Spring Security. Пароли хранятся как BCrypt-хеши.

## Запуск

Нужны JDK 17+ и Maven 3.9+.

В PowerShell сначала перейдите в папку проекта:

```powershell
cd 'C:\Users\vital\Desktop\Work VS\online-shop'
```

```powershell
mvn spring-boot:run
```

Откройте http://localhost:8080. Можно также собрать и запустить JAR:

```powershell
mvn clean package
java -jar target/online-shop-1.0.0.jar
```

При первом запуске добавляются 12 демонстрационных товаров и две учетные записи:

| Роль | Email | Пароль |
| --- | --- | --- |
| Покупатель | `user@shop.ru` | `user123` |
| Администратор | `admin@shop.ru` | `admin123` |

Эти пароли предназначены только для локальной демонстрации. Перед размещением приложения в сети их необходимо изменить.

## Возможности

- Покупатель: регистрация и вход, каталог с фильтрами, страница товара, профиль, корзина и оформление заказа.
- Корзина привязана к учетной записи и сохраняется в H2 между сессиями и перезапусками приложения.
- Администратор: создание, редактирование и удаление товаров, просмотр пользователей и заказов, изменение статуса заказа.
- Сервер пересчитывает стоимость заказа по текущим ценам товаров и не доверяет суммам из браузера.

Исходники сервера находятся в `src/main/java`, интерфейс — в `src/main/resources/static`.

## Проверка

Для проверки HTTP-сценариев запустите приложение на порту 18080 с временной базой:

```powershell
java -jar target/online-shop-1.0.0.jar --server.port=18080 --spring.datasource.url=jdbc:h2:mem:shopcheck
python scripts/smoke_test.py
```

Проверяются каталог, разграничение ролей, восстановление корзины после повторного входа, оформление заказа и управление товарами администратором.
