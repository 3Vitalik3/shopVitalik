# Курсовой проект по дисциплине "Программная инженерия" 
# Интернет-магазин (WebShop)

# Задание
Создайте сайт интернет магазина.  
На сайте должно быть 2 роли, покупатель и администратор. 
Покупатель может заходить в свой личный кабинет, корзин и страницу товаров. 
На странице товаров он может добавлять товары в корзину, производить фильтрацию товаров и открывать страницу товара, что бы посмотреть более подробную информацию о нем. 
Если пользователь покинул сайт при следующем заходе на него его корзина должна быть в том-же состоянии, что и в прошлой сессии 
Администратор может создавать новыые товары, редактировать и удалять их.
Реализуйте данный сайт используя java-spring,js, и любую удобную для вас сбд.

Данный проект представляет собой веб-приложение интернет-магазина с разграничением ролей покупателя и администратора.

# Интернет-магазин 

Данные товаров, пользователей, заказов и корзин хранятся в файловой базе H2 (`data/shop.mv.db`).

## Запуск

```powershell
mvn clean package
java -jar target/online-shop-1.0.0.jar
```

 Предложено 12 демонстрационных товаров и две учетные записи:

| Роль | Email | Пароль |
| --- | --- | --- |
| Покупатель | `user@shop.ru` | `user123` |
| Администратор | `admin@shop.ru` | `admin123` |


## Возможности

- Покупатель: регистрация и вход, каталог с фильтрами, страница товара, профиль, корзина и оформление заказа.
- Корзина привязана к учетной записи и сохраняется в H2 между сессиями и перезапусками приложения.
- Администратор: создание, редактирование и удаление товаров, просмотр пользователей и заказов, изменение статуса заказа.
- Сервер пересчитывает стоимость заказа по текущим ценам товаров и не доверяет суммам из браузера.

## Проверка

```powershell
java -jar target/online-shop-1.0.0.jar --server.port=18080 --spring.datasource.url=jdbc:h2:mem:shopcheck
python scripts/smoke_test.py
```
Проверяется каталог, разграничение ролей, восстановление корзины после повторного входа, оформление заказа и управление товарами администратором.
